# ShadowShield

Machine Learning-Based Detection of Sensitive Data Leakage in AI Applications

## Objective

ShadowShield is a browser-based privacy protection layer that detects
sensitive information in AI prompts before submission.

## Core Flow

User Types
    ↓
ShadowShield Extension
    ↓
Local Detection Engine
    ↓
Risk Assessment
    ↓
Allow / Warn / Redact / Cancel
    ↓
AI Application

## Technology Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- Regex
- FastAPI
- Chrome Extension Manifest V3
- JavaScript
- Streamlit

## Detection Approach

1. Pattern-based detection
2. Machine-learning classification
3. Local NLP detection where useful
4. Risk assessment
5. Sensitive information redaction
